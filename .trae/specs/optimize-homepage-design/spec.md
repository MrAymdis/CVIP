# 首页设计优化规格说明

## Why
当前首页设计存在搜索入口不够突出、平台介绍信息不够清晰的问题，用户难以快速理解平台核心价值。移除首页搜索框，将搜索功能统一引导至专门的搜索页面，同时优化平台介绍内容布局，提升用户体验。

## What Changes
- 移除首页 Hero 区域的搜索框组件
- 重新设计 Hero 区域布局，强化平台核心价值展示
- 优化统计数据卡片的视觉层次和可读性
- 增强功能特性介绍区块的信息传达效率
- 优化整体视觉动线和用户体验

## Impact
- Affected specs: 搜索功能（已迁移至独立搜索页面 `/search`）
- Affected code: `frontend/src/app/page.tsx`

## ADDED Requirements

### Requirement: 平台核心价值展示
首页应清晰传达平台的核心定位和主要功能

#### Scenario: 用户首次访问首页
- **WHEN** 用户首次访问首页时
- **THEN** 应立即展示平台名称、核心定位和主要功能模块入口
- **AND** 不应出现搜索框或搜索相关UI元素

### Requirement: 统计数据展示
首页应展示平台的关键数据指标

#### Scenario: 统计数据展示
- **WHEN** 用户查看首页统计数据区域
- **THEN** 应清晰展示数据源数量、CVE条目数、Exploit数量、数据更新频率等关键指标
- **AND** 数据应以直观卡片形式呈现

### Requirement: 功能特性介绍
首页应清晰介绍平台的主要功能特性

#### Scenario: 功能特性展示
- **WHEN** 用户浏览功能特性区域
- **THEN** 应展示至少三个主要功能模块及其简要说明
- **AND** 功能入口应可点击跳转至对应功能页面

## MODIFIED Requirements

### Requirement: 首页布局结构
原首页布局包含 Hero + 搜索框 + 统计卡片 + 功能介绍 + Footer

**新设计**:
- Hero 区域：平台名称 + 核心定位描述 + 导航入口按钮
- 统计卡片区域：关键数据指标展示
- 功能特性区域：主要功能模块介绍
- Footer：版权和致谢信息

## REMOVED Requirements

### Requirement: 首页搜索框
**Reason**: 搜索是独立功能模块，应在专门页面 `/search` 中提供完整搜索体验
**Migration**: 用户可通过导航栏"搜索"链接或 Hero 区域的"开始搜索"按钮访问搜索页面
